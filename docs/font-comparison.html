在墨色系统里
思考界面的呼吸感

2025·03·08 · 12 MIN READ · 67 VIEWS

真正的呼吸感来自节奏 — 密与疏交替, 重与轻互衬。这周重新走了一遍设计系统的色阶定义,发现自己之前把"留白"理解错了。

为什么禅意的设计往往会失败?因为我们误把"留白"理解为什么都不放。但禅师们的庭院从不是空的 — 一块石头, 一棵松, 一道沟纹砂的弧线。留白是节奏的一部分, 不是节奏的中断。

The same principle applies to typography: an em of breathing room above a heading isn't absence — it's presence framing the words that follow.

const lineHeight = fontSize * 1.75; // for serif body

真正的极简不是没有元素, 而是每个元素都有理由存在。

Implementation Spec · 落地参数

Next.js next/font/google 自动 self-host + subset, 不会有 FOIT。CJK 字体按需 subset, 仅加载实际用到的字符。

用途 方案 A (推荐) 加载方式
Display 大标题 Fraunces + Noto Serif SC next/font/google · weight 300-600 · variable
文章正文 (prose) Source Serif 4 + Noto Serif SC next/font/google · weight 400/500/600
UI / 列表 / 导航 Geist Sans + Noto Sans SC Geist 已加载, Noto Sans SC 通过 next/font/google 补
代码 / Marginalia JetBrains Mono next/font/google · weight 400/500

文章页 prose 容器加 font-serif 类即可切换;列表/UI 保持现状不动。
预估总字体下载: ~120KB (Latin) + 按需加载 CJK (使用频率高的字符首屏加载)。
