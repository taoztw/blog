把博客的 sidebar 重做了一遍，从原来的"功能列表"改成"信息流卡片"，加上了实时阅读进度和站点统计。直觉告诉我 —— 工具感强的产品都该让用户感到自己在系统里。

变化要点

  • 顶部 sticky 操作栏移除 —— 改为右下角 fixed FAB
  • 日期 header 改为时间线节点 + 英文日期（"May 25 · 周一"），有节奏感
  • 每条只保留"时间" + 内容 + 评论，去掉 author 区域和 Calendar 图标
  • 无 card 边框 —— hover 时整块淡淡变成 bg-ink-100
  • 编辑/删除按钮在 hover 时显示在右上角（图标按钮组）
  • 左侧细竖线 + 节点 = "日记本"的线性叙事感

FAB 规格

  • 尺寸：56 × 56，圆形，border-radius: 50%
  • 位置：fixed bottom: 24px; right: 24px（移动端 bottom: 16px; right: 16px）
  • 阴影：0 4px 16px rgba(45,37,32,0.18)，hover 时上浮 2px 加深阴影
  • 仅 admin 显示，未登录或普通用户不渲染
  • hover 时左侧弹出文字气泡，桌面端可保留无文字
  • z-index 高于内容但低于 Dialog/Sheet（建议 40）
